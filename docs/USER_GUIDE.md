# ImageClip 使用说明书

面向使用者的操作指南。开发者文档（算法、API、架构）见同目录 `README.md`。

---

## 1. 快速开始

```bash
# 1. 安装依赖（Node ≥ 18，推荐 20+）
npm install

# 2. 同时启动前端 + 后端（默认端口：前端 5174，后端 8787）
npm run dev

# 3. 浏览器打开
# http://127.0.0.1:5174
```

- 打开后点顶栏「载入示例」，三张带透明通道的蝴蝶图会被导入，方便快速体验。
- **资源库、视频、音频**等工作区的文件存放在 `data/library/`（运行时自动创建，与源码分离）。
- 视频功能需要本机 FFmpeg；水印去除可选安装 LaMa、YOLOv5、PP-OCRv4 等模型。没有这些也能正常用基础功能（透明裁剪、背景去除、图片裁剪、橡皮擦等全部不依赖 FFmpeg / 模型）。

- 资源库、视频、音频有独立的文件面板，和素材列表之间可以互相「转入编辑」。

## 3. 各工作区使用指南

### 3.1 资源库（键 `1`）

统一管理 `data/library/` 里的图片 / 视频 / 音频。

- **上传**：顶栏「导入」按钮，或把文件直接拖到面板里。
- **目录**：右键面板 → 新建子目录；双击进入，面包屑回到上级。
- **批量改名**：选中多个文件 → 「批量改名」→ 预览新旧对照表确认后提交。支持编号（起始值 / 步长 / 补零位数）、查找替换、前后缀、大小写。
- **查重高亮**：同一文件夹内一键比对文件 SHA256，重复项亮黄色标记（只标记不做操作）。
- **一键转入编辑**：把资源库文件取成 Blob → 自动切到对应的图片工作区；批量选中多张时可以直接进入「透明裁剪」或「图片裁剪」做批量处理。
- **下载**：预览窗口顶部下载按钮；批量下载走 ZIP 打包（不额外压缩）。
- **文件上限**：默认单文件 2GB、单目录最多 20000 个，均在服务端环境变量可调。

### 3.2 透明裁剪（键 `3`）

最常用的一键工具：自动扫描图片所有**不透明像素**，算出最小外接矩形（AABB），把四周透明区域整块切掉。

**界面**：左侧素材 → 中央画布（带裁剪框 + 四角尺寸标签，裁掉的区域压暗）→ 右侧参数面板。

| 参数 | 默认 | 说明 |
|---|---|---|
| 透明阈值 | 1 | Alpha ≤ 阈值的像素算透明。默认 1 最保守（只切全透明）；素材边缘有很淡的投影/噪点时往上调到 8~32 |
| 裁剪扩展（padding） | 0 | 正数向外扩（保留呼吸位），负数向内收（裁掉抗锯齿边缘），会被夹取到图片范围内 |
| 颜色背景模式 | 关 | 对白底 JPG / 截图启用：把 RGB 接近指定背景色的不透明像素也算背景 |
| 颜色容差 | 12 | 颜色背景模式下，三通道最大差值 ≤ 容差的像素算背景 |
| 计算引擎 | 浏览器 | 本地即时计算（不上传图片）。切到 Node 引擎会 POST 到服务端，**结果逐像素一致**（两端调用同一份算法源码） |

**结果视图**：按 `R` 或面板按钮在「源图」与「裁剪结果」之间切换。

**导出**：下载 PNG / WebP / JPG；「保存到资源库」默认落到 `data/library/导出/`；「批量打包」把素材列表全部裁完后打成 ZIP。

**精灵图（Sprite）**：勾选同尺寸的素材（例如图集透明裁剪的结果），在右侧「精灵图（Sprite）」区块把这一组按方阵拼成一张 PNG（保留透明通道）。列数填 `0` 为自动方阵，也可手动指定列数与帧间距；尺寸不同的素材会被跳过并在区块里提示。

### 3.3 图片裁剪（键 `4`）

自定义矩形裁剪，和透明裁剪互补。

- **内置比例**：1:1、4:3、3:2、16:9、9:16、4:5、3:4、2:3、自由比例。点击比例按钮会把当前裁剪框吸附到该比例。
- **手柄缩放**：8 个手柄，拖角按比例缩放，拖边自由缩放；拖裁剪框中央平移。
- **精确输入**：X / Y / 宽 / 高 四个数字直接输入像素值。
- **输出尺寸**：`原尺寸` 或 `自定义尺寸`（另一边自动按比例推算）。内置常用尺寸（头像 512、1080p、4K），也可保存自定义尺寸到 localStorage。
- **图集模式**：选中多张素材后，"图集模式"会取一个**共同的最大 AABB**（会忽略 ≤2 像素的近透明噪点），所有图用同一个相对框裁切，序列帧构图对齐。

### 3.4 背景去除（键 `5`）

从图片里抠出主体，去掉背景。支持三条路径：**参数抠图** / **AI 抠图**（后端模型）/ **套索 + 参数** 组合。

#### 3.4.1 参数抠图（默认）

按"颜色 + 连通性"抠图，零依赖、离线即时。

**核心参数**：

| 参数 | 默认 | 说明 |
|---|---|---|
| 容差 | 32 | 像素颜色与背景色的加权欧氏距离 ≤ 容差 → 算背景。调大调小影响抠图精度 |
| 只去除与边缘连通区域 | 开 | **最重要的开关**。默认开时：只抠从图片边缘向内可漫水到的区域。人物身上的白衣服不会被误抠（因为白衣服不与边缘连通）。关掉时：全图同色都会被抠掉 |
| 边缘羽化 | 2px | 让 alpha 平滑过渡，避免硬边锯齿 |
| 边缘收缩 | 0px | 先向内收再羽化，能去掉主体外沿残留的一圈底色 |
| 边缘颜色反混合 | 开 | 解半透明边缘的底色污染（`B = (I − α·C)/(1 − α)`），比单纯羽化效果好很多 |

**工具**：
- **套索**（默认激活）：手绘或智能吸附模式，用来限定"只抠选区内部"或"只抠选区外部"。智能套索会自动吸附到图像边缘。
- **取色器**：在图上点一下取背景色（可多次叠加）；也可以直接在面板里输入 `#rrggbb`。
- **平移**：拖动查看大图。
- **噪点** ✨（新增）：点击画面上的孔洞标记直接移除。

#### 3.4.2 噪点检测与逐个移除

去背景后，主体身上可能残留几个"像背景色一样的小像素点"——它们被主体边缘完全包围，不与图片边缘连通，所以连通性开关不会把它们抠掉。

ImageClip 会自动检测这些"孔洞"：

- **自动去噪**：面板里勾选后实时生效，把面积 ≤ 阈值（默认 2 像素）的小孔洞直接填掉。阈值可调 1~200 像素。
- **逐个点选**：切到「噪点」工具 → 画面上每个孔洞会叠一个中心圆圈（面积越大圈越大）→ 悬停时额外显示虚线覆盖框和面积标签 → 点击即移除该孔洞。
- **面板列表**：右侧「噪点处理」section 列出面积最大的 8 个孔洞（`面积 px @ 位置`），每行一个「移除」按钮，底部「一键移除全部孔洞」。
- **跟随撤销**：已移除的孔洞会跟随参数撤销 / 重做（参数重算后孔洞会被重新识别，但已标记移除的会再次被扣掉）。

#### 3.4.3 AI 抠图

切换到「AI 抠图」tab：后端模型直接输出一张主体 alpha 掩膜。参数抠图的羽化 / 收缩 / 反混合 / 孔洞去噪在 AI 路径下同样生效。

#### 3.4.4 应用到原图

预览默认最长边 1600px（保证交互跟手）。面板底部「按原图分辨率应用」才会用原图重算一次 —— 孔洞 bbox 会按预览 / 原图的尺寸比例反缩放回去。**批量抠图**只支持自动去噪（模板的手动孔洞位置无法复用）。

### 3.5 橡皮擦（键 `6`）

在原图上画掉不想要的像素（像素直接透明）。

- **模式**：擦除（`destination-out`）/ 还原（印章模式，用原图盖回去）。
- **参数**：笔刷直径 2~400px、硬度、强度。快捷键 `[` / `]` 调笔刷大小。
- **脏矩形撤销**：每一笔只记录笔迹包围盒，避免每次操作存整图（4K 画布 ≈ 96MB / 次）。历史上限 20 步。
- **导出**：生成新素材 / 仅下载 / 保存到资源库。

### 3.6 水印去除（键 `7`）

先自动检测 → 再去除 → 导出。

**三个引擎**（自动 = 依次尝试）：

| 引擎 | 适用 | 耗时（1060×802） |
|---|---|---|
| `反混合`（首选） | 半透明文字 / 平铺标记 / 角标 logo | ~0.4s（纯 JS） |
| `Opencv` | 不透明小块、彩色标记（Telea 修补） | ~0.5s |
| `LaMa` | 大面积缺失、不透明大标记（需要装模型） | ~3s / 512 窗口 |

**检测**：运行后画面上会把检出位置用**琥珀色虚线框 + 编号**标出来（不受掩膜叠加开关影响）；面板「结果」区显示覆盖百分比、置信度、候选区域数、耗时。

**手动调掩膜**：检测结果不理想时，可以用「画笔」直接在画面上涂掉水印区域。

**文本门控**（可选）：装了 PP-OCRv4 模型（4.5MB，CPU 推理）后，水印检测会被限制在画面**文字区域**内 —— 插画里的装饰高光、纹理脊线这类一次性结构不会再被误判成平铺水印。默认关闭。

### 3.7 像素笔绘（键 `9`）

像素级画笔 / 橡皮 / 吸管 / 平移。

- **显示像素网格**开关：放大到 400%+ 自动显示。
- **快捷键**：`B` 画笔 / `E` 橡皮 / `I` 吸管 / `H` 平移 / `G` 切换网格。
- **脏矩形撤销**：同橡皮擦。
- 导出 PNG 或直接生成新素材。

### 3.8 精灵图（图片处理 → 「精灵图」tab）

- **导入**：点右侧「导入 sprite 图」、把图片拖进窗口或 `Ctrl+V` 粘贴；导入后自动加入左侧素材列表并选中。
- **自动分隔**：按透明像素找分隔线，把连续的“有内容列 / 行”切成帧。导出时留过「帧间距」的 sprite 图可以直接切开，右侧会显示检测出的列数 × 行数。
- **网格**：帧紧贴、没有透明分隔线时改用网格，手动填写列数 / 行数按整图等分。
- **预览**：下方「整图切分」显示原图与帧框，点击格子即选中该帧；上方「动画预览」按当前帧矩形裁绘，只显示这一帧。
- **播放**：右侧调帧率（1–60 FPS）与是否循环，点「播放 / 暂停」；也可用 `空格` 播放暂停、`←/→` 逐帧。
- 帧只保存矩形、不复制像素，所以调整切法不会额外占内存，也不会改动原图。

### 3.9 视频（键 `2`）

- **探测**：ffprobe 自动给出时长 / 宽高 / 帧率 / 编码 / 码率。
- **完整时间轴**：服务端 FFmpeg 均匀抽帧拼成胶片条，叠加自适应刻度（0.5s ~ 600s 里挑一个让标签 ≤12 个的步长）、手动标记（红竖线）和播放头。
- **截帧**：固定间隔 / 均匀 N 帧 / 手动标记点。单次最多 120 帧，输出默认到 `关键帧/<视频名>/`。
- **提取音频**：mp3 / m4a / wav / flac，默认落到 `音频/`。
- 没装 FFmpeg 时，视频仍能播放、能打标记；只有截帧 / 音频 / 时间轴缩略图会返回明确错误。

### 3.10 音频（键 `8`）

- **频谱 + 波形**：canvas 绘制上层热力图（360 列 × 96 个对数频段）、下层峰值包络。完全不依赖 FFmpeg（Web Audio 本地解码）。
- **裁剪**：单击定位播放头，横向拖动框选保留区间（选区可循环试听），裁剪后生成新的 PCM16 WAV 写入资源库（原文件不动）。
- 采样率与声道跟随源文件，不做重采样。

## 4. 参数调优参考

### 背景去除：什么时候自动去噪开 / 关

- **默认关**：自动去噪会让孔洞直接消失，无法逐个点选。想手动移除某些特定孔洞时请关掉自动去噪，切到「噪点」工具或面板列表逐个点。
- **开**：场景是"视频截帧批量处理"、"序列帧"、"大量素材套同一套参数" —— 逐张点选不现实，直接自动去噪阈值设到 2~5px 最省心。
- **阈值怎么选**：预览面板会实时更新孔洞计数。阈值 ≥主体身上正常纹理的最小像素块才是安全的，否则会把实际内容当成孔洞。建议先开自动去噪 → 拖滑块调到刚好把要去掉的噪点都覆盖 → 关掉自动去噪切换到「噪点」工具手动补几个大的再应用。

### 透明裁剪阈值

| 素材类型 | 推荐阈值 | 说明 |
|---|---|---|
| 边缘干净的 PNG | 0~1 | 默认最保守，不切内容 |
| 带淡投影 / 抗锯齿边缘 | 8~32 | 把投影噪点一起切掉 |
| 边缘干净但要给主体留呼吸 | 0~1 + padding 2~6 | 阈值 1 不切内容，padding 外扩保住呼吸位 |
| 白底 JPG / 截图 | 打开「颜色背景」+ 容差 12~30 | Alpha 为 0，必须靠颜色判定 |

### 背景去除容差

- **图片整体明暗差不大**：32~48（默认 32）
- **渐变底**：调大到 48~80，或手动叠加多个取色点
- **底图跟主体同色区域多**：调小容差 + 打开「只去除与边缘连通」+ 用套索限定

### 水印去除

| 场景 | 推荐组合 |
|---|---|
| 半透明文字 / 平铺标记 | 反混合 + 默认参数 |
| 粗大红底印章 / 不透明色块 | Opencv 修补（Telea） |
| 大面积缺失 / 老照片修复 | LaMa（需要装模型） |
| 单个角标 logo（重复性检测会漏检） | 用「画笔」直接涂掩膜，或打开文本门控 |

## 5. 导出与保存

- **下载 PNG**：所有图片工具的默认导出格式（保留 alpha）。
- **保存到资源库**：结果落到 `data/library/导出/`（背景去除 / 透明裁剪 / 橡皮擦 / 像素笔绘）或工作区内（视频截帧 → `关键帧/`，音频裁剪 → `音频/`）。
- **批量导出 ZIP**：透明裁剪、图片裁剪、背景去除的"批量"按钮，纯 ZIP store 模式（图片本身已经是压缩格式，不二次压缩）。
- **临时会话**：顶栏「临时会话」按钮可以把当前素材列表 + 参数存到 `data/sessions/`，下次打开自动恢复。

## 6. 常见问题

**Q: 为什么切到 Node 引擎没有反应？**
A: 后端 8787 端口没启动。看顶栏右侧状态（绿 / 红圆点）。没装 FFmpeg 时视频功能降级，其他一切正常。

**Q: 橡皮擦写画布写得越来越慢？**
A: 每次操作都把笔迹包围盒记录下来，历史上限 20 步；恢复上限后旧记录被清空。4K 画布每步 96MB 左右，机器内存 <16GB 时建议一次只导入几张素材。

**Q: 自动去噪把主体眼睛当成孔洞去掉了？**
A: 「孔洞」的定义是"被 255 像素完全包围的 0 值孤岛"。如果主体本身有一个被抠掉的区域（比如圆眼睛），它周围全是 255 去除像素，会被判定为孔洞。调大「最小孔洞面积」阈值（眼睛通常远大于 100px）、或关掉自动去噪切到手动点选。

**Q: 视频截帧/音频提取提示 FFMPEG_NOT_FOUND？**
A: FFmpeg 没装好。把 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 的 essentials 压缩包解压，保证 `D:\thirdparty\ffmpeg\bin\ffmpeg.exe` 与 `ffprobe.exe` 同时存在即可（路径固定，不需要改 PATH）。启动后 `GET /api/video/health` 可以看到所有搜索过的路径。

**Q: 图片上限 64MB / 6400 万像素怎么办？**
A: 浏览器端和服务端都有这个硬限制。手机拍摄的超高像素照片请先在系统相册里裁剪 / 缩小再导入。

**Q: 抠图后边缘有淡边？**
A: 勾选「边缘颜色反混合」（默认已经开），调大「羽化」到 4~6px，必要时加 1~2px「收缩」。边缘颜色反混合比单纯羽化效果好一个量级——它是解方程还原底色，而不是模糊掩盖。

**Q: 大模型（AI 对话）图片外发吗？**
A: 默认端点都是 `127.0.0.1`（本机 DeepSeek 视觉侧车 或 Ollama），图片不出本机。只有你显式切到「云端」提供方时图片才会离开（UI 会标 ⚠️ 云端）。

## 7. 故障排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 前端 `npm run dev` 起不来 | 端口 5174 被占 | 关掉占用进程，或改 `web/vite.config.js` 的 `port` |
| 后端连不上（状态栏红点） | 8787 端口被占 / Node 版本不够 | `node -v` ≥ 18；关掉占用进程后重启 `npm run dev:server` |
| `npm install` 报 `EPERM` / `EACCES` | Windows 权限 / esbuild 子进程限制 | `npm install --cache .npm-cache`；受限环境里 `npm run build:restricted` |
| 中文文件名乱码 | 终端编码 | PowerShell 里 `chcp 65001`；Node 里默认 UTF-8 不会有问题 |
| 水印去除慢 | 检测 + 去除耗时；第一次调模型还要加载权重 | 后端启动后第一次会花 19s 加载模型；之后常驻缓存。实时交互建议用浏览器引擎（本地即时） |
| 资源库缩略图没更新 | 缩略图按 `路径 + mtime` 缓存 | 删掉 `data/library-thumbs/` 对应文件或等列表刷新 |
